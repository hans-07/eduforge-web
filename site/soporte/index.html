Contacto y soporte

Encuentra respuestas o prepara un reporte para el equipo.

¿Puedo trabajar offline?

El editor y los ejemplos incluidos funcionan offline. Los recursos HTTPS que agregues a un proyecto necesitan conexión.

¿Cómo hago una copia?

Abre Biblioteca y usa Copia de seguridad para descargar el proyecto en JSON.

Errores y sugerencias

Para un error, incluye versión, sistema operativo, pasos y resultado esperado. Para una sugerencia, explica la tarea que quieres resolver. El canal público está pendiente de confirmación.

Divulgación responsable

Cuando esté disponible el canal de seguridad, reporta las vulnerabilidades en privado. Incluye la versión, el impacto y los pasos necesarios para entender el problema. Omite datos personales y credenciales.
