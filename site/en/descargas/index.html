    Documented compatibility

    The desktop edition and portable launcher target 64-bit Windows. The HTML edition opens in Edge or Chrome. Minimum memory and storage requirements are awaiting verification.

    Installation

    Once the official installer is published, run it on 64-bit Windows. For the HTML edition, open the official file directly in Edge or Chrome.

    SHA-256 verification

    On Windows, run Get-FileHash -Algorithm SHA256 -LiteralPath 'file.exe' in PowerShell. Compare the result with the published checksum for that file.
