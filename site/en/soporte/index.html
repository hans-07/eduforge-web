Contact and help

Find answers or prepare a report for the team.

Can I work offline?

The editor and bundled examples work offline. HTTPS resources you add to a project require a connection.

How do I make a backup?

Open the Library and choose Backup to download the project as JSON.

Bugs and suggestions

For a bug, include the version, operating system, steps, and expected result. For a suggestion, describe the task you want to accomplish. A public channel is awaiting confirmation.

Responsible disclosure

When a security channel is available, report vulnerabilities privately. Include the version, impact, and steps needed to understand the issue. Omit personal data and credentials.
