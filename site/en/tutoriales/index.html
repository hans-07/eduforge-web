Learn with a project

Follow the Studio workflow with a small exercise.

Create your first project

In the Library, create a project or open Campus Reserva and choose Edit a copy. Export a JSON backup to save your progress.

Design a screen

In Design, choose a canvas size and add a field and a button. Select each component to adjust its position and appearance in the inspector.

Connect an event

In Logic, select the button event and connect an action below its header. Choose Test to run the screen and check which blocks ran.

Work with data

In Data, create a table or import a CSV. In Logic, connect one Column value block for each row value in header order.

Export and test

Generate a standalone HTML file or a 64-bit Windows executable. Open the export and check navigation from the first page.

Ideas by field

Track materials in engineering, organize reading notes in the humanities, or practice with an inventory in business studies.
