About EduForge

A free tool for learning software development through projects.

Mission

Make software creation accessible to students in any field through a visual environment that works offline.

Vision

Help more students design, test, and share apps they create as part of their studies.

The project

EduForge Studio brings together an interface designer, a block editor, and export tools. The editor's source code is private. The founder biography is awaiting confirmation.
