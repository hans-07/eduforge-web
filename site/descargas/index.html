Estado de publicación

Consulta aquí las versiones oficiales de EduForge Studio.

Versión estable

Aún no hay una versión estable pública disponible. La versión documentada en el proyecto es 0.4.0.

Compatibilidad documentada

La edición de escritorio y el lanzador portátil se preparan para Windows de 64 bits. La edición HTML se abre en Edge o Chrome. Los requisitos mínimos de memoria y almacenamiento están pendientes de verificación.

Instalación

Cuando se publique el instalador oficial, ejecútalo en Windows de 64 bits. Para la edición HTML, abre el archivo oficial directamente en Edge o Chrome.

Verificación SHA-256

En Windows, ejecuta Get-FileHash -Algorithm SHA256 -LiteralPath 'archivo.exe' en PowerShell. Compara el resultado con la suma publicada para ese archivo.

Historial

Las fechas, tamaños, sumas y notas aparecerán cuando haya una publicación oficial.
