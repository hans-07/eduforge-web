Sobre EduForge

Una herramienta gratuita para aprender desarrollo de software haciendo proyectos.

Misión

Acercar la creación de software a estudiantes de cualquier carrera con un entorno visual que funciona offline.

Visión

Facilitar que más estudiantes puedan diseñar, probar y compartir aplicaciones creadas como parte de su aprendizaje.

El proyecto

EduForge Studio reúne un diseñador de interfaces, un editor de bloques y herramientas de exportación. El equipo mantiene privado el código fuente del editor. La reseña del fundador está pendiente de confirmar.
